# Sample Data

Sample video data is not bundled yet because 360-degree videos are usually large and may contain privacy-sensitive information.

To try Geo360 View, use your own MP4 video and GPX track recorded during the same run.

Optional reference point CSV files can be used when you have point data such as KP markers, utility poles, bridge names, facility IDs, or inspection points.

## Reference CSV

Use UTF-8 CSV with latitude/longitude columns.

```csv
id,name,latitude,longitude
1991,Route A KP:1991,35.97173562,136.2038756
2034,Route A KP:2034,35.97156058,136.2037934
```

When editing with Microsoft Excel, choose `CSV UTF-8 (Comma delimited) (*.csv)`.
