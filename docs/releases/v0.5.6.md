# Geo360View 0.5.6

This regular release improves video-frame validation, viewer-server lifecycle
handling, and troubleshooting. The QGIS plugin now defaults to English.

## Changes

- Validate OpenCV seek/read positions before saving images, reject invalid reads,
  and regenerate images/cache entries created before position validation.
- Limit FFmpeg decoder threads to a maximum of eight on OpenCV builds supporting
  `CAP_PROP_N_THREADS`. A rejected limited open is never retried without the limit.
- Clamp forward navigation to the last video frame and reject out-of-range requests.
- Check viewer-server ownership and loaded code generation, refuse stale/unrelated
  servers, and stop owned servers on plugin Exit or normal QGIS shutdown.
- Remove the application-wide keyboard filter implicated in the reported Ubuntu
  QGIS/SIP crash path; panel and canvas navigation remain local to their widgets/tools.
- Provide a read-only environment diagnostic for QGIS and the running viewer.
- Default the QGIS panel/messages to English and save an explicit language preference.

## Installation and requirements

Download **Geo360View-0.5.6.zip** and use QGIS Plugin Manager → Install from ZIP.
GitHub's automatically generated source archives are not QGIS installation ZIPs.
Close the plugin and its viewer, and restart QGIS after upgrading.

The metadata range remains QGIS **3.40–4.2.2**. OpenCV **4.8 or newer with FFmpeg
support is recommended**. OpenCV 4.6 cannot enforce the decoder thread limit;
some videos on high-CPU-count systems may still fail validation. Displaying an
existing cached image alone does not demonstrate successful fresh decoding.
FFmpeg CLI is not required and is not automatically used as a slow extraction fallback.

Operation has been reported on Windows QGIS 3.40/4.2.2 and Ubuntu QGIS 3.44.7.
The Ubuntu results distinguish an eight-CPU system with OpenCV 4.6 from a
20-CPU system using a dedicated OpenCV 4.8.1 installation. See the repository's
environment validation record for the exact evidence and outstanding checks.

## Language and diagnostics

To use Japanese, run this in the QGIS Python console, then restart QGIS:

```python
from qgis.PyQt.QtCore import QSettings; QSettings().setValue("Geo360View/display_locale", "ja")
```

Use `"en"` to switch back to English. This controls the plugin panel and messages;
browser-viewer labels are separate. There is no panel language selector yet.

To collect the environment report:

```python
from Geo360View.environment_diagnostics import print_environment_report; print_environment_report()
```

Include OS/QGIS/OpenCV versions, the requested frame, and whether the panel or
browser shows the problem. Redact personal paths as needed before sharing reports.

Verify the ZIP with the accompanying **Geo360View-0.5.6.zip.sha256** file.
