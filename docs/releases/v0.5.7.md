# Geo360View 0.5.7

GPX/MP4からVideo GPX Pointsを再生成すると、管理中の以前の撮影点レイヤを自動削除し、最新のレイヤへ置き換えます。Shift再調整時の手動削除が不要になります。

- 新しいレイヤの追加成功後に置換し、生成失敗時は以前のレイヤを保持します。
- POI・マーキングは保持し、古い撮影点のクリックツール・終了時保存の参照を解除します。

検証: Pythonユニットテスト127件成功。利用者が新規生成およびShift再調整後のレイヤ置換を実機確認済み。ZIPの全収録ファイル一致・CRC・SHA256を確認済み。

QGISの「ZIPからインストール」で添付ZIPを導入してください。SHA256ファイルを同梱しています。
